Visio-Voice

An image-captioning project using an InceptionV3 + LSTM encoder-decoder pipeline for accessible visual understanding.

View Repository

Project Overview

Visio-Voice extracts image features with InceptionV3 and generates natural-language captions with an LSTM decoder. The project focuses on producing clear, human-readable image descriptions.

Architecture

  • Encoder: InceptionV3 visual feature extractor
  • Decoder: LSTM sequence generator
  • Task: Image captioning / text generation from image content
